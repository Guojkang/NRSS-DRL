# Data

Put well-log CSV files here:

- `Well_A.csv` — source well
- `Well_B.csv` — zero-shot target
- `Well_C.csv` — few-shot calibration target

Required columns: `Depth, PE, DEN, AC, GR, RS, CNL, M2R1, TOC`

The field datasets used in our experiments are not redistributed here due to confidentiality.
